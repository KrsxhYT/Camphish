Camera Security Testing Tool for Educational Use

CamPhish is an educational cybersecurity tool designed to demonstrate camera security vulnerabilities. Learn about penetration testing techniques and how to protect against camera-based attacks.

What is CamPhish?

CamPhish is an educational tool that demonstrates camera security vulnerabilities by simulating capture techniques. It hosts simulated websites to demonstrate how camera permissions can be exploited if users are not cautious. This tool is designed for cybersecurity education and penetration testing training.

A GPS location capture simulation has been added in the latest version to demonstrate location tracking risks.

Installation & Requirements

Requirements

This educational tool requires PHP for the webserver and wget for downloading dependencies:

# Install required packages for educational use
apt-get -y install php wget unzip

Installation (Kali Linux/Termux)

# Clone the repository for educational purposes
git clone https://github.com/KrsxhYT/CamPhish.git

# Navigate to the directory
cd CamPhish

# Run the main educational script
bash camphish.sh

Cleanup

To remove logs and unnecessary files after educational use:

bash cleanup.sh

Note: This will also remove all demonstration files and saved locations.
